# Про.Путевые Листы (PutList)

Десктопное приложение для автоматизации выписки путевых листов легкового автомобиля (**Типовая межотраслевая форма № 3**), расчёта ГСМ (бензин / газ), построения маршрутов по карте и ведения журнала учёта движения путевых листов (**Форма № 8**).

## Внесённые исправления
1. **Простановка даты составления путевого листа в шапке бланка (`templates/put-list-f3.xlsx` и `parser_f3.py`)**:
   - В шаблоне `templates/put-list-f3.xlsx` в строке 5 перед подчеркнутым объединенным диапазоном `M5:AY5` установлена метка `'от'` (ячейка `L5`) и убран дублирующий суффикс `' г.'` в `AZ5`. Теперь и готовая сборка `Про.Путевые Листы.exe`, и модуль `parser_f3.py` автоматически записывают дату составления (например, `16 ноября 2026 г.`) в шапку путевого листа.
2. **Исправление обновления карточки водителя (`database.py`)**:
   - В методе `DatabaseManager.update_driver` имена столбцов SQL-запроса синхронизированы со схемой таблицы `drivers` (`cat, exp, tab, ser, num`).
3. **Модернизация картографического маршрутизатора (`gui.py`)**:
   - Добавлено автоматическое геокодирование адресов через **Nominatim OpenStreetMap API** (`geocode_address`): если при добавлении точки маршрута её ещё нет в таблице `locs`, программа сама определяет координаты и сохраняет их в базу `waybills.db` без необходимости вручную кликать по карте.
   - Ускорен расчёт дорожного графа и километража (`get_road_distance`): убрана задержка на неактивном зашитом ключе Яндекс.Маршрутизации, используется прямой запрос к **OSRM Driving API** (`overview=full&geometries=geojson`) с поддержкой опционального `YANDEX_ROUTING_API_KEY` (с исправленным порядком координат `lat,lon`) и офлайн-расчётом по формуле гаверсинуса (`× 1.25`).
4. **Полная структура исходных модулей Python**:
   - `main.py` — точка входа приложения
   - `gui.py` — графический интерфейс ERP-системы (`CustomTkinter` + интерактивная карта `TkinterMapView`)
   - `parser_f3.py` — заполнение Excel-шаблона Формы № 3 (`templates/put-list-f3.xlsx`)
   - `database.py` — работа с базой данных SQLite (`waybills.db`) и пересчёт цепочки пробега/остатков ГСМ
   - `logic_gsm.py` — расчёт норм расхода топлива и расстояний по GPS-координатам
   - `export.py` — выгрузка реестра путевых листов и Журнала учёта по Форме № 8
